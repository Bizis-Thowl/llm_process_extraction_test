Der Prozess "Schadensfallanlage" beginnt mit einem Start-Ereignis. Wie der Name schon sagt, gibt das Start-Ereignis an, wo ein bestimmter Prozess beginnt. 

Die erste Aufgabe im Prozess ist "Polizeiberichtsdatenbank durchsuchen". Eine Aufgabe ist eine atomare Aktivität, die in einem Prozess enthalten ist. Eine Aufgabe wird verwendet, wenn die Arbeit im Prozess nicht in feinere Prozessdetails unterteilt ist. In diesem Fall umfasst die Aufgabe die Suche nach einem Polizeibericht in einer Datenbank. Das Ergebnis dieser Aufgabe ist ein "Polizeibericht", bei dem es sich um ein Datenobjekt handelt. Datenobjekte liefern Informationen darüber, welche Aktivitäten durchgeführt werden müssen und/oder was sie hervorbringen. Dem Datenobjekt "Polizeibericht" ist eine Textanmerkung zugeordnet, die zusätzlichen Kontext zu den Quellen des Datenobjekts liefert. Textanmerkungen dienen im Allgemeinen dazu, dem Leser eines BPMN-Diagramms zusätzliche Textinformationen zur Verfügung zu stellen.

Die nächste Aufgabe ist "Datei zusammenstellen". Diese Aufgabe nimmt das Datenobjekt "Polizeibericht" aus der vorherigen Aufgabe entgegen und benötigt zudem das Datenobjekt "Schadensunterlagen". Die Aufgabe umfasst das Erstellen einer Datei unter Verwendung der bereitgestellten Daten. Die Ausgabe dieser Aufgabe ist eine "Schadensdatei", ein weiteres Datenobjekt, das an die nächste Aufgabe weitergeleitet wird.

Die dritte Aufgabe ist "Schadensschätzung berechnen". Diese Aufgabe nimmt das Datenobjekt "Schadensdatei" aus der vorherigen Aufgabe entgegen. Die Aufgabe umfasst die Berechnung einer Schätzung für den Schaden. 

Die vierte Aufgabe lautet dann "Aktionsplan erstellen". Für diese Aufgabe wird das Datenobjekt "Checkliste für den Aktionsplan" benötigt, dem eine weitere Textanmerkung zugeordnet ist: "Dokumentenmanagementsystem", die die Quellen des Datenobjekts angibt. Die Aufgabe umfasst die Erstellung eines Aktionsplans. Das Ergebnis dieser Aufgabe ist ein "Aktionsplan", ein Datenobjekt, das an die nächste Aufgabe weitergeleitet wird.

Die beiden Aufgaben "Datei erstellen" und "Aktionsplan erstellen" können als "Schadensbearbeiter" gruppiert werden. Eine Gruppe ist eine Zusammenfassung von Objekten, die derselben Kategorie angehören.

Nach dieser Gruppe folgt als fünfte Aufgabe "Verhandlung der Schadensbegleichung". Diese Aufgabe übernimmt das Datenobjekt "Aktionsplan" aus der vorherigen Aufgabe. Die Aufgabe umfasst die Verhandlung einer Einigung über die Schätzung.

Die letzte Aufgabe ist "Benachrichtigung des Anspruchstellers". Diese Aufgabe umfasst die Benachrichtigung des Anspruchstellers.

Der Prozess endet dann mit einem Endereignis. Das Endereignis gibt an, wo ein Prozess endet.
